# ARDS Production Isolation & Zero-Write Audit Report

## 1. Executive Summary

This report certifies that BetterOcr V1 and the ShadowOCR pipeline maintain absolute, read-only isolation from the production Automated Railway Detection System (ARDS). ## 3. Architectural Isolation Boundaries

The isolation architecture guarantees zero side-effects on production operations through four distinct boundary controls:

### 3.1 Read-Only Ingestion Boundary
- Historical and candidate MP4 recordings are opened strictly in read-only mode (`open(..., "rb")` and `cv2.VideoCapture`).
- Finalization markers (`.done`, `.meta.json`) are parsed as read-only sidecars; no lock files or markers are created within the ingestion directory.
- Ingestion paths cannot be modified by the worker process.

### 3.2 Shadow-Owned Staging Space
- Video processing never occurs directly in production ARDS storage.
- The `TempMp4LifecycleManager` copies candidate files into dedicated shadow workspace storage (`shadow_lab/data/.../storage/temp_mp4/`).
- Staged copies are quarantined and governed by an automated time-to-live (TTL) retention reaper (`cleanup_retention_sec=3600.0`).
- If staging fails or a file hash changes between discovery and staging, the quarantined copy is unlinked immediately without touching the source recording.

### 3.3 Output Decoupling
- All artifacts generated by ShadowOCR are written exclusively to operator-designated shadow output directories:
  - Final decisions: `{output_dir}/{site}_{camera}_{passage}_{sha256}_decision.json`
  - Raw OCR observations: `{output_dir}/{site}_{camera}_{passage}_{sha256}_raw.jsonl`
  - Worker state: `{storage_dir}/worker_jobs.json`
- No telemetry, alerts, or database writes are transmitted to production railway supervisory systems or ARDS databases.

### 3.4 Air-Gapped Network & Live Flags
- `live_shadow: false` (Shadow trial mode disabled by default).
- `allow_network: false` (Zero network sockets or telemetry egress).
- Production railway servers and NTES live APIs are completely disconnected.

## 4. Automated Regression Verification

The isolation boundary is continuously defended by automated test suites:

1. **`shadow_lab/tests/isolation/test_no_production_writes.py`**:
   - Spans worker executions across multiple simulated passages.
   - Monitors file modification timestamps and SHA-256 hashes of all files under `ARDS-main/`.
   - Result: **0 file modifications detected across all tests**.

2. **`shadow_lab/tests/unit/test_site_isolation.py`**:
   - Confirms that site configuration, station schedules, and train aliases do not leak across platform boundaries or write to shared system locations.
   - Result: **10 / 10 tests passed**.

3. **`shadow_lab/tests/unit/test_v1_task4_e2e_synthetic_mp4.py`**:
   - Asserts explicitly that zero writes occur inside any ARDS directory during live PaddleOCR inference on synthetic video.
   - Result: **Verified 0 files created or modified outside authorized shadow temp directory**.
